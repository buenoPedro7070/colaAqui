# Landing Page — Cola Aqui Adesivos

Landing page responsiva criada com HTML, CSS e JavaScript puro.

## Como abrir

1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. Para publicar, envie todos os arquivos da pasta para seu serviço de hospedagem.

## Arquivos

- `index.html` — estrutura e conteúdo
- `styles.css` — identidade visual e responsividade
- `script.js` — menu mobile, animações e ano automático
- `logo-cola-aqui.png` — logo fornecida
